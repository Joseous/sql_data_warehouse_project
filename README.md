# sql_data_warehouse_project

Welcome to data Warehousing project **Repository**

This project covers a comprehensive warehousing, from extracting and building data warehouse to genetrate data that can be used to give actionable insights.

1. **Bronze Layer**: The layer houses raw data extracted from source stored in CSV files. Data is loaded to SQL Server Database
2. **Silver Layer**: This layer involves data cleansing, standardization, and normalization processes to prepare data for analysis.
3. **Gold Layer**: The data stored in this layer is ready for reporting and analytics.

   # Project Overview
   This project involves:
   
   * **ETL Pipelines**: Extracting, Transforming and Loading data from source system into warehouse
   * **Data Modeling**: Optimization of data for Analytics Queries that is developing dimensions and facts tables
   * **Analytics & Reporting**: Creating SQL based analytics query.

   # Project requirements:
   To develope modern data warehouse, the following is involved:

   * **Technology Used**: SQL Server.
   * **Data source**: Importing data from the source systems, in this case ERP and CRM in CSV files format
   * **Data Quality**: Data must be cleaned perfectly before subjecting the same for reporting and analytics.
   * **Integration**: Data from both source to be combined into a single, user friendly data model for analytics
   * **Scope**: Focuses on latest data only.

    # Reporting and Analytics
   
   Develop SQL-based analytics to deliver detailed insights into:
   * Customer Behaviour
   * Sales trends
   * Product performance
